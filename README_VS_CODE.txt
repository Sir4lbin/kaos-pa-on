KAOS PÅ ÖN – MULTIPLAYER

1. Öppna denna mapp i VS Code.
2. Öppna Terminal -> New Terminal.
3. Kör: npm install
4. Kör: npm run server
5. Låt terminalen vara öppen.
6. Öppna Kaos_pa_On_multiplayer_READY.html i Chrome/Edge.
7. Tryck Skapa rum och skicka rumskoden till en kompis.

VIKTIGT:
Detta fungerar mellan flera datorer först när servern är hostad på internet.
Just nu använder spelet 127.0.0.1, vilket bara är din egen dator.
För att kompisar på andra datorer ska kunna ansluta behövs en publik WebSocket-server.
